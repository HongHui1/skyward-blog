整理 SkyCity 的内容时，我想先为自己的学习留下一处起点。

这不是一份用来展示“技术栈”的清单，也不是一篇写给技术大佬看的经验总结。我只是想回答一个很朴素的问题：走到现在，我究竟学过什么，又真正留下了什么？

如果只把课程和语言排在一起，C、Java、C++、Rust、数据结构、数据库、软件工程……看起来好像已经接触了很多。但“接触过”不等于“掌握了”。目前的大部分知识仍停留在课程、练习和课程设计的层面，还没有经过足够多的真实项目，把它们连成一个完整的体系。

所以，这篇文章更像一次诚实的盘点。

## C：第一次让计算机按步骤做事

我的 C 学得并不深，大致走过基本语法、条件与循环、函数、数组、指针，再到链表附近。

现在回头看，C 留给我的最重要的东西并不是记住了多少语法，而是第一次体会到：计算机不会理解模糊的想法，问题必须被拆成明确、可以执行的步骤。

例如，统计一个整数的二进制表示中有多少个 `1`，看起来只是一个很小的练习，却需要先想清楚怎样取出每一位、怎样判断、怎样累计结果。那时的我还不懂多少算法，但已经开始学习把“我想得到什么”翻译成“程序接下来应该做什么”。

C 是我的起点。它没有让我立刻学会开发软件，却第一次让我理解了程序是怎样运转起来的。

## Java：程序也可以由对象协作

到了 Java，我开始比较系统地接触类与对象、封装、继承、多态、接口、异常处理、输入输出以及集合。

从 C 转到 Java，变化不只是语法。以前我更习惯把程序看成一串从上到下执行的指令；Java 则让我开始理解，程序也可以被拆成不同的对象，每个对象拥有自己的数据和职责，再通过彼此协作完成任务。

那时写下的很多代码依然只是课程练习，但“类应该负责什么”“对象之间应该怎样联系”这些问题，已经在悄悄改变我理解程序的方式。

## 数据结构：第一次认真思考数据怎样组织

相比单纯学习一门语言，数据结构阶段的内容更密集，也更系统。

从顺序表、链表、栈和队列，到二叉树、Huffman 编码、图的遍历、拓扑排序和最小生成树，我接触到的问题越来越不像单纯的语法练习。迷宫、表达式求值、Josephus 环之类的题目，也让我慢慢意识到：同一个问题，数据采用什么结构保存，会直接影响解决它的方式。

如果说编程语言是在学习“怎样表达”，那么数据结构教给我的，是“应该怎样组织”。这也是我目前接触过的知识中，最值得重新回头梳理的一部分。

## Rust：语言规则也能约束内存

Rust 是另一种很不一样的体验。

我接触了所有权、借用、可变引用、模式匹配和生命周期，也写过类似下面这样的函数声明：

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str
```

我对 Rust 的理解还很基础，但它让我第一次比较清楚地意识到：不同编程语言的区别不只是关键字和写法不同。语言本身的规则，也可以约束程序员怎样管理数据与内存，并尽可能在程序运行之前发现问题。

这种感觉很新鲜，也让我开始对“语言为什么要这样设计”产生兴趣。

## 数据库：从处理变量，到管理数据

学习数据库以后，视角又从一个程序里的变量，扩展到了需要长期保存和相互关联的数据。

我使用过 MySQL 和 DBeaver，练习过增删改查、多表连接、索引和视图。真正值得记住的并不只是 SQL 的写法，而是这些设计背后的取舍：索引可以加快查询，却会增加更新和维护的成本；视图可以封装复杂查询，也可以限制使用者能够看到的数据范围。

这让我开始意识到，数据并不是“存进去就结束了”。怎样组织、怎样查询、怎样保证边界清晰，本身就是系统设计的一部分。

## 软件工程：代码能运行，不等于软件已经完成

随着课程继续，我又接触到需求分析、系统设计、UML、模块划分、测试以及人机交互。

这些内容让我逐渐明白，写代码只是完成软件的一部分。一个功能为什么存在、不同模块怎样配合、出现问题后怎样定位、界面是否容易理解，都需要在代码之外认真考虑。

我也接触过一些 C++，能够用 HTML、CSS 和 JavaScript 写或修改简单的页面。但这些目前仍是基础，不足以被称为“熟练”。与其继续增加一长串语言名字，我更希望以后能通过实际项目，把已经见过的知识真正连接起来。

## 接下来：用 408 重新整理这张地图

回头看这段学习经历，我已经见过了软件世界里的不少组成部分，却常常只是分别学过，还没有完全理解它们怎样联系在一起。

接下来，我想把 408 作为一条新的学习主线，重新整理数据结构、计算机组成原理、操作系统和计算机网络。数据结构是对过去知识的复习与加深，其余几部分则能帮助我继续回答一些更底层的问题：程序怎样被机器执行，内存和进程怎样工作，信息又怎样通过网络抵达另一台计算机。

我不想一开始就立下过于宏大的目标。比起说“学完 408”，我更希望把每次真正弄懂的问题、写过的练习、踩过的坑和阶段性的想法记录下来。等到有合适的小项目，再尝试把语言、数据结构、数据库和软件工程方法放在一起使用。

这就是我目前的地基。

它还不完整，也谈不上处处牢固，但那些看起来零散的砖块已经在那里。建立 SkyCity，也是想给这个慢慢搭建的过程留下痕迹：既记录已经走过的路，也记录接下来怎样把它们连接起来。
